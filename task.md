# Stupid Ideas Hackathon (Ottawa F26) - Challenge Details

## Overview
- **Competition**: Stupid Ideas Hackathon (Ottawa F26)
- **Devpost**: https://stupideas-ottawa-f26.devpost.com/
- **Theme**: "Build something stupid"
- **Requirements**:
  - What to build: Something stupid.
  - What to submit: A short paragraph to describe what you've created, screenshots to show it off, a README showing team contributions, and a link to the public GitHub repo.

## Prize Tracks
1. **General Stupidest**: $CAD 500 in cash (1 winner)
2. **General Stupider**: $CAD 250 in cash (1 winner)
3. **General Stupid**: $CAD 100 in cash (1 winner)
4. **Stupidest AI**: Build an AI agent that does something stupid (1 winner)
5. **Stupidest Button**: Make useless hardware (or software) that does something cool when you push a button (1 winner)
6. **Stupidest Metric**: Track something useless (1 winner)
7. **Stupidest API**: Design an API that returns stupid data ($CAD 67 in cash, 1 winner)
8. **The Great Bob Award**: Post on social media (2 winners)
